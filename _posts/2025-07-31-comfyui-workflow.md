tl;dr: Export the JSON and upload the JSON data on [jsonkeeper.com](https://www.jsonkeeper.com/) and share the link with people.

If you want to share your ComfyUI workflow with someone, it's super simple!

Click on Save here, and save the JSON file:

![ComfyUI Save button](https://i.postimg.cc/HkVKS2t4/image.png)

The file will save in your downloads folder.

Open the file in a text editor and copy the content.

Go to [jsonkeeper.com](https://www.jsonkeeper.com/) and paste it in the box. If you want to edit the JSON later, sign up to save it in your account.

When you save it, you get a link.

Share that link with the person you want to share your workflow with.

They can save the JSON from the link (with Ctrl/Cmd + S) and then click on "Load", and upload the JSON.
